# AI Playground

Небольшие самостоятельные веб-вещицы, сделанные вместе с ИИ (Claude, Anthropic).
Каждый проект — один HTML-файл: открой в браузере, ничего ставить не нужно.

## Проекты

| Папка | Что это |
|---|---|
| [`dance-crew/`](dance-crew/) | **AI Dance Crew** — танцующая команда ИИ в спортивных костюмах. Нажми на персонажа — соло. Музыка генерируется прямо в браузере (Web Audio). |
| [`ai-band/`](ai-band/) | **THE NODES — AI Band** — группа ИИ. |
| [`greeting-card/`](greeting-card/) | **Поздравление** — плавающие буквы с настройками шрифта, цвета и анимации, конфетти, своё фото на фон и **своя музыка (MP3)**: выбираешь кусочек песни, пишешь текст и сохраняешь готовую открытку одним файлом, фото (PNG) или видео со звуком. |

## Демо

После включения GitHub Pages: `https://<твой-ник>.github.io/<репозиторий>/`

## Как запустить локально

Открой `index.html` (или `dance-crew/index.html`) в браузере.

## Примечания

- Эмблемы нарисованы по мотивам и не являются официальными логотипами.
- Ключей и серверов нет, всё работает в браузере. Единственное внешнее: шрифты поздравления подгружаются с Google Fonts (нужен интернет).
- Музыка и фото, которые ты выбираешь в поздравлении, никуда не загружаются, они остаются на твоём устройстве.
- Если выкладываешь готовую открытку с чужой песней, помни про авторские права на музыку.
